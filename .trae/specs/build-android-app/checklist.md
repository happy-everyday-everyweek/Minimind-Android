- [x] Android 应用包含三个顶级页面（开始、推理、训练），通过底部导航栏切换
- [x] UI 配色使用黑白灰色调，不使用任何其他颜色
- [x] 开始页面显示应用简介、后端状态指示器、快速开始卡片、最近活动记录、训练流程通俗说明
- [x] 推理页面支持模型选择、对话交互、流式输出、推理参数配置、思考过程展示、可折叠参数说明
- [x] 训练页面展示完整训练流程步骤：预训练 -> SFT -> 知识蒸馏 -> LoRA -> 强化学习 -> Agentic RL
- [x] 非必须训练步骤支持跳过，跳过后显示"已跳过"状态
- [x] 每个训练步骤提供面向普通用户的详细说明，使用通俗类比
- [x] 预训练步骤支持数据集选择、模型配置、训练参数配置和实时 loss 监控，附说明
- [x] SFT 步骤支持基础权重选择、数据集选择、训练参数配置和实时 loss 监控，附说明
- [x] 知识蒸馏支持配置外部 LLM API 作为教师模型，不限定厂商，无预设或暗示性选项
- [x] LoRA 微调支持自定义数据集上传和 LoRA 参数配置，附 rank/alpha 说明
- [x] 强化学习步骤支持 DPO/PPO/GRPO 三种算法选择和对应参数配置，附三种算法通俗说明
- [x] Agentic RL 提供可视化环境编辑器，支持工具定义、奖励函数规则编辑、测试场景配置，各区域附说明
- [x] Agentic RL 支持 AI 辅助生成奖励函数（调用配置的 LLM API）
- [x] 后端 Linux 实例在手机上自动启动和初始化，无需用户手动配置
- [x] 后端 API 服务提供 REST API 和 WebSocket 接口
- [x] 首次安装后自动完成初始化（Linux 实例、Python 环境、Tokenizer 预置），实现开箱即用
- [x] 训练过程支持实时监控（loss 曲线、日志、进度）和控制（暂停/恢复/停止）
- [x] 训练断点自动保存，支持从断点恢复训练
- [x] 模型权重管理功能（列表、下载、删除、导出）
- [x] 数据集管理功能（列表、上传自定义 jsonl、预览、删除）
- [x] LLM API 配置管理（保存/读取 API 地址、Key、模型名），均为纯输入框，无预设或暗示性选项
- [x] 系统资源占用上限设置（CPU、内存、最大训练进程数），训练前检查资源限制
- [x] Tokenizer 使用项目已有的训练好的分词器，不暴露训练步骤给用户
