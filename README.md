# MiniMind App

在手机上开箱即用地体验大语言模型的推理与训练全流程。

## 项目简介

MiniMind App 是基于 MiniMind 构建的 Android 移动应用，旨在让普通用户无需任何专业背景，只需在手机上安装本应用，即可完整体验大语言模型从推理到训练的全过程。应用采用前后端分离架构，前端为 Android 原生界面，后端运行在手机本地的 Linux 实例中，所有计算均在本地完成，无需依赖云端服务。

无论你是想与语言模型对话，还是想亲手训练一个属于自己的模型，MiniMind App 都提供了直观的图形界面和详尽的功能说明，让每一步操作都清晰可懂。

## 核心特性

- Android 原生应用，安装即用，无需手动配置环境
- 前后端分离架构，前端 Kotlin + Jetpack Compose，后端 FastAPI
- 三个顶级页面：开始、推理、训练，底部导航栏一键切换
- 完整训练流程：预训练 -> SFT -> 知识蒸馏 -> LoRA -> 强化学习 -> Agentic RL
- 非必须步骤可跳过，按需选择训练路径
- 知识蒸馏支持配置任意兼容 OpenAI API 协议的外部 LLM API
- Agentic RL 提供可视化环境编辑器，无需手写代码即可定义工具和奖励函数
- 支持系统资源占用上限设置，避免影响手机正常使用
- 推理与训练并重，既可对话体验，也可深度训练
- 所有功能均有面向普通用户的详细说明

## 应用架构

应用采用前后端分离架构，所有服务运行在用户手机本地：

```
+---------------------------------------------+
|              Android 原生前端                 |
|         Kotlin + Jetpack Compose             |
|                                              |
|  +----------+  +----------+  +-----------+  |
|  | 开始页面  |  | 推理页面  |  | 训练页面   |  |
|  +----------+  +----------+  +-----------+  |
|                                              |
+------------------+---+-----------------------+
                   |   |
          HTTP REST API  WebSocket
                   |   |
+------------------+---+-----------------------+
|           后端 Linux 实例                     |
|         (Termux / PRoot)                     |
|                                              |
|  +------------------+  +------------------+  |
|  |   FastAPI 服务    |  |  训练与推理引擎   |  |
|  +------------------+  +------------------+  |
|                                              |
|  +------------------------------------------+|
|  |        MiniMind 核心模块                   ||
|  |  model / trainer / dataset / scripts      ||
|  +------------------------------------------+|
+----------------------------------------------+
```

前端通过 HTTP REST API 进行配置和操作调用，通过 WebSocket 接收推理流式输出和训练进度推送。后端运行在手机上的 Linux 实例中，封装了 MiniMind 的训练脚本和推理接口，所有计算均在本地完成。

## 应用页面

### 开始页面

开始页面是应用的首页，提供应用概览和快捷入口：

- 应用简介：了解 MiniMind App 的功能与用途
- 后端服务状态指示器：实时显示后端 Linux 实例的运行状态
- 快速开始卡片：一键进入"开始对话"或"开始训练"
- 最近活动记录：查看最近的推理对话和训练任务

当后端服务异常时，页面会显示错误状态和"重新初始化"按钮，方便用户快速恢复。

### 推理页面

推理页面提供与语言模型的对话交互功能：

- 模型选择器：列出所有可用的模型权重，一键切换
- 对话界面：输入消息，模型实时流式回复
- 推理参数配置：可调节 temperature（生成随机性）、top_p（采样范围）、max_tokens（最大生成长度）、open_thinking（是否展示思考过程）
- 思考过程展示：开启后可查看模型的推理思路

### 训练页面

训练页面展示完整的训练流程，包含以下六个步骤：

1. **预训练 (Pretrain)** -- 必须步骤，从零开始训练语言模型的基础能力
2. **有监督微调 (SFT)** -- 必须步骤，教会模型以对话形式回答问题
3. **知识蒸馏** -- 可选步骤，借助外部大模型提升学生模型的能力
4. **LoRA 微调** -- 可选步骤，用少量数据快速定制模型行为
5. **强化学习 (RL)** -- 可选步骤，进一步优化模型的输出质量
6. **Agentic RL** -- 可选步骤，训练模型使用工具完成复杂任务

每个步骤显示当前状态（未开始 / 进行中 / 已完成），可选步骤可随时跳过。训练过程中可实时查看 loss 曲线、训练日志和进度信息。

## 训练流程详解

### 预训练 (Pretrain)

预训练是训练语言模型的第一步，也是必须完成的步骤。在这一阶段，模型会阅读大量的文本数据，学习语言的基本规律，包括词汇、语法和常识知识。可以把它理解为"广泛阅读"的过程 -- 就像一个人通过大量阅读来积累知识，模型也通过阅读海量文本来理解语言。

**配置项说明：**

- 数据集：选择用于训练的文本数据集，提供不同规模的选项
- 模型配置：设置模型的维度和层数，决定模型的大小和能力
- 训练参数：包括学习率、批次大小、训练轮次、保存间隔等
- 输出权重名称：为训练产出的模型权重命名，方便后续识别

训练过程中，你可以实时观察 loss（损失值）的变化。loss 下降意味着模型正在学习，数值越低说明模型对语言的理解越准确。

### 有监督微调 (SFT)

有监督微调是训练流程的第二步，同样是必须完成的步骤。经过预训练的模型虽然掌握了语言规律，但还不知道如何以对话的方式回答问题。SFT 阶段通过"问答对"形式的训练数据，教会模型理解用户的问题并给出恰当的回答。可以把它理解为"学习对话技巧"的过程 -- 就像一个人虽然读了很多书，但还需要学习如何与人交流。

**配置项说明：**

- 基础权重：选择预训练阶段产出的模型权重作为起点
- 数据集：选择问答格式的训练数据集
- 训练参数：包括学习率、批次大小、训练轮次、最大序列长度等

完成 SFT 后，模型就可以进行基本的对话交互了。

### 知识蒸馏

知识蒸馏是一个可选步骤，其核心思想是让一个强大的"教师模型"来指导你的"学生模型"学习。教师模型会对你提供的问题给出高质量的回答，学生模型则学习模仿这些回答，从而在较短的训练时间内获得更好的效果。可以把它理解为"名师辅导" -- 有经验的老师可以帮助学生更快地掌握知识。

**配置项说明：**

- 教师模型 API 配置：填写外部 LLM 服务的 API 地址、API Key 和模型名称，支持任何兼容 OpenAI API 协议的服务
- 学生模型权重：选择需要提升的模型权重
- 蒸馏数据集：配置用于蒸馏的问题集
- 训练参数：设置蒸馏过程的训练参数

如果你没有外部 LLM API，可以跳过此步骤，不影响后续训练流程。

### LoRA 微调

LoRA 微调是一个可选步骤，它使用一种高效的参数微调技术，只需调整模型中很少的参数，就能让模型适应特定的任务或风格。与全量微调相比，LoRA 的训练速度更快、所需数据更少，非常适合用少量数据快速定制模型的行为。可以把它理解为"专项训练" -- 用少量有针对性的练习来提升某方面的能力。

**配置项说明：**

- 基础权重：选择需要微调的模型权重
- LoRA 数据集：选择微调数据集，支持上传自定义 jsonl 格式数据
- LoRA 参数：包括 rank（影响微调强度）和 alpha（影响学习幅度）
- 训练参数：设置微调过程的训练参数

LoRA 微调特别适合想让模型学习特定风格或领域知识的场景。

### 强化学习 (RL)

强化学习是一个可选步骤，旨在进一步优化模型的输出质量。通过奖励信号来引导模型生成更符合期望的回答，减少不恰当或低质量的输出。本步骤提供三种算法供选择：

- **DPO (直接偏好优化)**：通过对比"好的回答"和"差的回答"来训练模型，让模型学会倾向于生成更好的回答。适合有成对偏好数据的场景，训练过程简单稳定。

- **PPO (近端策略优化)**：通过训练一个奖励模型来评价回答的质量，然后根据评价结果优化生成策略。适合需要细粒度控制输出质量的场景，训练效果更精细。

- **GRPO (分组相对策略优化)**：对同一个问题生成多个回答，通过组内比较来评估回答质量，无需单独训练奖励模型。训练效率高，适合资源有限的场景。

**配置项说明（因算法而异）：**

- DPO：基础权重、偏好数据集、beta 参数（控制偏好强度）
- PPO：基础权重、RL 数据集、KL 系数（约束偏离程度）、clip epsilon（限制策略更新幅度）
- GRPO：基础权重、RL 数据集、分组大小、KL 系数、loss 类型（grpo / cispo）

训练过程中可以观察 reward 曲线，了解模型输出质量的提升趋势。

### Agentic RL

Agentic RL 是训练流程的最后一步，也是一个可选步骤。它训练模型成为能够使用工具的智能体，让模型不仅能回答问题，还能调用工具来完成更复杂的任务，例如查询信息、执行计算、操作数据等。可以把它理解为"学习使用工具" -- 就像一个人不仅要有知识，还要会使用各种工具来解决实际问题。

本步骤提供可视化环境编辑器，无需编写代码即可配置智能体的训练环境：

- **工具定义**：通过可视化界面定义模型可以使用的工具，包括工具名称、参数格式和功能描述
- **奖励函数配置**：通过可视化规则编辑器定义奖励条件，例如格式正确性、工具调用合法性、结果匹配等；也可通过外部 LLM API 辅助生成奖励函数代码
- **测试场景配置**：设定测试用例，包括用户输入、预期工具调用和预期输出，用于验证智能体的行为

**训练配置项：**

- 基础权重：选择需要训练的模型权重
- 算法选择：GRPO 或 CISPO
- 训练轮次及其他参数

训练过程中可以查看智能体的行为日志，了解模型是如何学会使用工具的。

## 系统资源管理

由于训练和推理任务会占用较多的系统资源，MiniMind App 提供了资源占用上限设置功能，让你可以在性能与体验之间取得平衡：

- CPU 使用率上限：限制后端进程的 CPU 占用比例
- 内存使用上限：限制后端进程的内存占用大小
- 存储空间管理：查看和管理模型权重、数据集等文件的存储占用

通过合理设置资源上限，可以在运行训练或推理任务的同时，避免手机出现卡顿或发热严重的情况。

## 快速开始

1. 下载并安装 MiniMind App 的 APK 文件
2. 首次打开应用，系统将自动初始化后端 Linux 实例，包括安装 Python 环境、PyTorch 及项目依赖
3. 初始化完成后，即可进入应用开始使用
4. 在"推理"页面选择模型权重，即可与模型对话
5. 在"训练"页面按照步骤指引，从预训练开始训练自己的语言模型

## 技术栈

**前端：**
- Kotlin
- Jetpack Compose

**后端：**
- Python
- FastAPI (Web 服务框架)
- PyTorch (深度学习框架)
- Uvicorn (ASGI 服务器)

**运行环境：**
- Termux / PRoot (Android 上的 Linux 环境)
